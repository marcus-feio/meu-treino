# MEU TREINO v3 🏋️‍♂️🏃‍♂️

Aplicativo web para acompanhamento de musculação, corridas e controle de ritmo de treino.

## 🚀 Recursos
- Fundo em preto puro (`#000000`) com logo animada de eletrocardiograma (ECG) vermelha.
- 5 abas principais: Treino de hoje, Meu Treino, Minha Corrida, Progresso e Avaliações.
- Timer com acréscimo estilo futebol para descanso de séries.
- Registro completo de corridas, circuitos mistos e cálculo de pace.
- Calendário responsivo ajustado para visualização em smartphones.
- Backup de dados em formato JSON.
